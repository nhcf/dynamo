系统框架：三层与两类数据流

入口与编排客户端 → Frontend → 预处理 / 模型选择 → Router → 聚合 Worker 或 Prefill / Decode
Rust 基础能力LLM 流水线 · KV Router · Runtime / 发现 / 传输 · KVBM · 后端契约与 Sidecar
Python 扩展启动与配置 · 引擎适配 · Planner / Profiler · 自定义处理器
Kubernetes 控制面CRD → reconcile → Pod / Service / 探针 / 监控发现
观测与反馈Metrics / Logs / Trace → 采集存储 → 看板 / 告警；部分运行指标也由 Planner 查询

请求控制流不等于 KV 数据传输；监控指标不等于路由实时状态事件。每章先标明所属路径，再进入实现。Router 可以内嵌于 Frontend，也可以独立部署。
