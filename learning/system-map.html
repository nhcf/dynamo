07 / 四种常用运行形态

形态主路径需要额外判断
聚合一个 generation worker 同时执行上下文与生成chunked Prefill、缓存、批量与 ITL 干扰
PDPrefillRouter → Prefill + Decode，engine 协调 KVCompleted / Bootstrap、拓扑兼容、staged KV 清理
SidecarDynamo planes → native engine RPCproto 能力、独立启动、指标采集与实验支持矩阵
分层 / globalGlobal Router 选 pool → local Router 选 worker当前 grid 策略和 Relay consumer 是否实际接线

多节点 TP 是单个模型引擎的并行分片；DP 是多个请求副本/秩组；Prefill/Decode 是职责划分。三者可以组合，不能用‘有多个 Pod’推断是 PD 或跨 DC。混合聚合/PD 拓扑需按真实请求 worker attribution 验证。
