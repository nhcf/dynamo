02 / 三种形态，复用职责而非强行等同实现

形态请求路径主要 owner
既有 Python 后端Runtime Python endpoint → request handler → engine Python API各 backend 的 main / worker_factory / init_llm / handlers
common/backend SDKPython BaseEngine → PyO3 → Rust Worker / EngineAdapterWorker 负责统一生命周期，Engine 负责引擎行为
Rust SidecarDynamo planes → Rust Worker / adapter → native gRPC（特定路径也可 HTTP）→ engineSidecar 转换契约，引擎独立启动/运行

common/backend 是与旧入口并行的路径，不能称整个 Python 适配已统一迁移。Sidecar 在该版本文档中标为 Experimental；支持矩阵和 native proto 能力须逐后端/版本核对。Dynamo 在引擎之上编排，不接管其 CUDA kernel、attention 或内部调度器。

252    /// Abort an in-flight request (optional, default no-op).
253    ///
254    /// Called by the framework only when `ctx.stopped()` or `ctx.killed()`
255    /// fires — i.e. when the client or operator explicitly cancels. It is
256    /// NOT called when the response stream is simply dropped (e.g. TCP
257    /// reset, consumer-side timeout without cancellation).
258    ///
259    /// For cleanup that must happen on ANY drop path (releasing an
260    /// accelerator slot, freeing a request handle), put the release logic
261    /// inside the `generate` stream body using RAII — a guard whose
262    /// `Drop` runs when the stream is dropped, however that happens. Use
263    /// `abort` only for out-of-band notifications (e.g. telling a remote
264    /// scheduler to cancel compute early).
265    async fn abort(&self, _ctx: Arc<dyn AsyncEngineContext>) {}
266
267    /// Whether in-flight KV transfers are done, so `cleanup` may release GPU
268    /// memory. The `Worker` polls this on prefill workers between the grace
269    /// period and [`cleanup`](LLMEngine::cleanup):
270    ///
271    /// - `Ok(Some(true))`  — quiescent; exit the drain loop now.
272    /// - `Ok(Some(false))` — busy; poll again next tick.
273    /// - `Ok(None)`        — no introspection (default); poll until the drain
274    ///   budget expires, then cleanup. Never frees KV early.
275    /// - `Err(_)`          — logged and treated as `Ok(None)`.
276    ///
277    /// Aggregated/decode workers are never polled. Override only if the engine
278    /// can observe transfer completion (e.g. a connector or scheduler).
279    async fn is_quiescent(&self) -> Result<Option<bool>, DynamoError> {
280        Ok(None)
281    }
282
283    /// Release all engine resources. Called exactly once.
284    ///
285    /// `Worker` guarantees:
286    ///
287    /// * `cleanup` runs after [`start`](LLMEngine::start) succeeded
288    ///   *and* on shutdown — the common case.
289    /// * `cleanup` also runs after `start` raised, on the partial
290    ///   state the engine may have allocated before failing (inner
291    ///   LLM handle, sockets, background tasks). Implementations
292    ///   **must** be null-safe: guard each resource with an `is
293    ///   None` / `Option::is_some` check so a partially constructed
294    ///   engine can be released without panic.
295    /// * `cleanup` is **not** called when `start` was never invoked
296    ///   (pre-start shutdown via SIGTERM during distributed runtime
297    ///   construction). Engines whose constructors allocate
298    ///   resources must release them via `Drop` rather than rely on
299    ///   `cleanup`.
300    ///
301    /// `cleanup` must also be idempotent: a second call after a
302    /// successful first call must return `Ok(())` without re-entering
303    /// teardown (NCCL groups and similar fail noisily on double-free).
