01 / PD 分离究竟拆开了什么

Dynamo 把一次逻辑生成请求编排到 Prefill 与 Decode 两类资源池，由引擎的交接协议搬运或复用 KV。Prefill 处理输入上下文，Decode 逐步生成后续 token；它们通常分别偏计算密集与访存密集，但实际瓶颈随模型、批量和输入输出长度变化。

层职责关键边界
Frontend / PrefillRouter发现角色、选择实例、编排交接与 Decode转发 token/元数据，不经 Frontend 搬运 KV 张量
Backend adapter把统一请求转换为 SGLang / vLLM / TensorRT-LLM 协议三种引擎交接对象与完成时点不同
Engine / KV connector分配 KV、协调接收、执行传输与生成NIXL 配置本身不证明实际走 RDMA / GPUDirect
Discovery / events / metrics发布角色与端点、缓存状态和负载、记录运行结果KV 事件、KV 数据、Trace 是三条不同路径
