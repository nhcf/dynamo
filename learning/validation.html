02 / 不同工具回答不同问题

层能验证不能由此证明
单元 / property / paused-clock纯函数、状态迁移、排序、不变量跨进程 GPU 推理正确性或吞吐

Mocker live servingFrontend / Router / Runtime 的实际请求路径和模拟 engine 行为真实模型输出质量、CUDA 或 RDMA 性能
Offline replay虚拟时间下策略、缓存和 workload 的可比行为完整线上墙钟开销

AIPerf + real backend客户端测得的实际部署延迟与吞吐仅凭总时延定位某一源码函数

本章分析验证工具实现并提供实验设计；本次没有执行推理、replay、故障注入或 GPU benchmark。文档浏览器校验不替代这些行为验证。

195/// Run `replay` with `scope` installed for the offline replays constructed on this thread.
196///
197/// The scope replaces any outer scope entirely, so a nested replay never registers into a router
198/// control registry it does not own. The previous scope is restored when `replay` returns or
199/// unwinds.
200pub fn with_replay_scope<T>(scope: ReplayScope, replay: impl FnOnce() -> T) -> anyhow::Result<T> {
201    let lag_ms = scope.kv_event_lag_ms;
202    anyhow::ensure!(
203        lag_ms.is_finite() && lag_ms >= 0.0,
204        "kv_event_lag_ms must be finite and non-negative, got {lag_ms}"
205    );
206    struct Restore(ReplayScope);
207    impl Drop for Restore {
208        fn drop(&mut self) {
209            let previous = std::mem::take(&mut self.0);
210            REPLAY_SCOPE.with(|current| *current.borrow_mut() = previous);
211        }
212    }
213    let _restore = Restore(REPLAY_SCOPE.with(|current| current.replace(scope)));
214    Ok(replay())
215}
