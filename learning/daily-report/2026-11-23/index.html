统计口径

  • 统计七个模型的 Chat Completions 和 Messages POST 请求，匹配模型路由的 zero2x 请求也计入。模型按匹配的网关日志条目数从多到少排列。
  • TTFT 有效请求为具有有效首段计时的网关流式请求。TTFT 采用首次流式响应体回调耗时。
  • TPOT 有效请求为 HTTP 2xx、无网关异常标记、有有效首段和流关闭计时、且至少输出两个 Token 的流式请求。TPOT 将流关闭耗时减去首段耗时，再除以输出 Token 数减一。总耗时可能包含尾部 usage 和结束帧。
  • 两项延迟按外部请求 ID 去重。缺少对应指标所需的有效计时或 Token 数据的请求，从该指标的分子和分母中排除。无有效样本时，该指标暂无法判定。
  • 请求可用率为 1 减去全天 5xx 条目数除以有效请求条目数。有效请求取 2xx、3xx、5xx，排除 4xx 和状态码 0 等未归类记录。429 比率为 429 条目数除以全部匹配网关日志条目数。
